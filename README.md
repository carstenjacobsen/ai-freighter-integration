# AI Freighter Integration

_Time Estimate: 20 mins (Vibe Coding)_

Freighter is a browser extension wallet provided by the Stellar Development Foundation. It provides users a way to interact with Soroban tokens directly from the web browser.

## Why Use Freighter Wallet?
* **Import any Stellar wallet** - easily import accounts using a recovery phrase
* **Non-Custodial - users maintain** full control of their private keys and assets
* **No Fees** - no added wallet fees, just Stellar’s network cost
* **Built-in DEX swaps** - swap tokens instantly without leaving your wallet

Learn more about Freighter Wallet and get started with these resources:

* [Documentation](https://docs.freighter.app)
* [Freighter Website](https://freighter.app)
* [Freighter GitHub](https://github.com/stellar/freighter)
* [Stellar Guide](https://developers.stellar.org/docs/build/guides/freighter)

## Vibe Coding
Claude Code is capable of writing code that integrates the Freighter Wallet into your project. You can ask it to write code for specific functionalities, such as retrieving the user's public key, signing transactions, or handling authentication. This can help you quickly implement Freighter Wallet integration without having to write all the code yourself.

A simple prompt to get started could be:

```
create a website that implements the stellar freighter wallet
```

This will typically generate a basic website with Freighter integration, including code to connect to the wallet, retrieve the user's public key, balances and send XLM to other accounts.
